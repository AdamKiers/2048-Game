2048 Game
=========

Description
-----------
2048 Game is a classic 2048 game implemented in C++ using SFML for graphics.
The goal is to combine tiles to reach 2048!

This version is portable and includes an installer that creates a shortcut on the desktop.

ZIP Contents
------------
The ZIP file contains:
- 2048_Game_Installer.exe    -> the game installer
- assets/             -> fonts and images needed by the game
- README.txt          -> this file

Note: You do NOT need Visual Studio or SFML installed. Everything needed is included in the installer.

Installation
------------
1. Unzip the contents of the ZIP to any folder on your computer.
2. Double-click 2048_Game_Installer.exe in Output to run the installer.
3. Follow the instructions to install the game.
4. A desktop shortcut will be created for easy access.

Default installation location:
C:\Program Files (x86)\2048 Game\
You can choose a different folder during installation.

Running the Game
----------------
- Launch the game by clicking the shortcut on your desktop.
- The game works offline and does not require any additional software.
